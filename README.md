# HBF — Havila Bdellium et Fils

Site vitrine HTML / CSS / JavaScript, version modernisée de [hbf.bj](https://www.hbf.bj/).

Textes, couleurs (bleu marine + rouge) et contenu officiels conservés. Nouveau logo (globe + HBF).

## Pages

- `index.html` — Accueil
- `activites.html` — Nos activités
- `realisations.html` — Nos réalisations
- `a-propos.html` — À propos et équipe
- `contact.html` — Coordonnées et formulaire
- `politique-confidentialite.html` — Politique de confidentialité
- `mentions-legales.html` — Mentions légales

## Lancer en local

Ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 4173
```

Puis allez sur http://127.0.0.1:4173/

## Notes

- Les photos et logos partenaires sont ceux publiés sur hbf.bj.
- Le formulaire de contact ouvre un e-mail vers `hbf@hbf.bj`.
- Interface FR / EN / 中文 via le sélecteur en haut à droite.
